01 / AI SYSTEMدر حال توسعه

MR_SIAVASH_HUB_AI

پروژهٔ هاب برای هماهنگی قابلیت‌های هوشمند، جریان‌های کاری و ابزارهای تولید و مدیریت محتوا.

مسئله، معماری، وضعیت و شواهد

مسئله: ساخت یک محیط یکپارچه برای هماهنگی عامل‌ها، مدل‌ها، وظایف و جریان‌های کاری، بدون وابستگی پنهان به سرویس‌های پولی.

رویکرد مستندشده: هستهٔ ماژولار FastAPI و SQLite، احراز هویت مالک، کنترل سیاست و تأیید عملیات حساس، ثبت رویدادهای ممیزی، رابط مدل تایپ‌شده و Worker جداگانه برای اجرای کارهای صف‌شده.

وضعیت قابل ادعا: پروژه در حال توسعه و با مسیر local-first است. Ollama و OpenRouter اختیاری و غیرفعال به‌صورت پیش‌فرض‌اند؛ اجرای دلخواه Shell و انتشار اجتماعی خارجی در وضعیت مستندشده فعال نیستند. این صفحه ادعای سرویس عمومی Production ندارد.

تغییرات شش Commit اخیر: افزودن ایندکس برای جست‌وجوی audit مالکیت وظایف Telegram؛ به‌روزرسانی runbook اتصال Cloudflare Local Bridge؛ پیش‌بررسی ریسک پیشنهادهای تخصصی؛ انتشار cancellation در زنجیرهٔ inference و delegation؛ الزام پروفایل‌های تأییدشده برای پیشنهاد مدل؛ و تقویت تحلیل ایستای NEXUS برای تشخیص verify=False در فراخوانی‌های زنجیره‌ای Requests و HTTPX. تحلیل NEXUS مبتنی بر AST و read-only است؛ کد هدف را اجرا نمی‌کند و متن منبع را در یافته‌ها نمایش نمی‌دهد.

آخرین شواهد: fcfde61 · ۱۱ نوامبر ۲۰۲۶. این آخرین commit شاخهٔ main است و فقط پایداری Linux FFmpeg CI را با بررسی SHA-256 دارایی دانلودشده بهبود می‌دهد؛ آخرین commit کاربردی پیش از آن f8e52ea است. پنج workflow روی commit جاری موفق شدند: Backend CI، CI اصلی، اسکن دفاعی Python، اعتبارسنجی Windows Launcher و Video Render Integration. پروژه همچنان local-first و در حال توسعه است؛ این شواهد به‌معنی سرویس عمومی Production یا اتصال زنده به سایت نیست.

02 / DIGITAL PRODUCTنسخهٔ عمومی

MR_SIAVASH_AI

وب‌سایت هویت دیجیتال، آکادمی، پشتیبانی، جست‌وجو و فضای کار محلی با مرزهای امنیتی مشخص.

مسئله، معماری، وضعیت و شواهد

مسئله: ایجاد یک فضای فارسی‌محور برای کشف ماژول‌ها، آموزش، مدیریت کارهای محلی و راهنمایی کاربر.

قابلیت‌های منتشرشده: کاتالوگ ماژول‌ها و جست‌وجوی سراسری، آکادمی با ۶ مسیر و ۳۰ فصل، دورهٔ Python با ۱۲ درس، شش تمرین JavaScript در محیط iframe محدودشده با Web Worker قابل توقف، پیشرفت محلی و استودیوی پیش‌نویس محتوای محلی.

پشتیبانی و حریم خصوصی: راهنمای محلی حالت پیش‌فرض است. حالت دستیار هوشمند آنلاین فقط پس از رضایت جداگانه برای همان سؤال، متن همان سؤال را به Gateway می‌فرستد. ثبت، پیگیری و پاسخ به تیکت تنها وقتی فعال می‌شود که آمادگی Gateway، پایگاه داده و سیاست نگهداری امن تأیید شوند. حساب کاربری مصرف‌کننده، همگام‌سازی ابری فضای کار و اتصال زنده به عامل‌های MR_SIAVASH_HUB_AI فعال نیستند.

شواهد کیفیت: ۲۶۴ تست خودکار موفق، آزمون واقعی Chromium، ممیزی axe/WCAG 2.1 سطح A/AA برای پنج صفحه و اعتبارسنجی مهاجرت‌های D1؛ انتشار GitHub Pages نیز با موفقیت انجام شده است. Service Worker در نسخهٔ v50 قرار دارد. آخرین نسخهٔ منتشرشده: 29a23ac · ۱۱ نوامبر ۲۰۲۶.

03 / COMMERCEدر حال توسعه

Gshop

پروژهٔ فروشگاهی با تمرکز بر تجربهٔ خرید، مدیریت محصول، موجودی و پنل مدیریت.

مسئله، معماری، وضعیت و شواهد

مسئله: توسعهٔ فروشگاه فارسی پوشاک ورزشی با رابط RTL و مسیرهای مدیریت محصول و سفارش.

معماری مستندشده: رابط فروشگاهی، پنل مدیریت و API مبتنی بر Cloudflare Workers و D1.

وضعیت و محدودیت: مخزن در حال توسعه است. README صریحاً تأکید می‌کند تست‌های خودکار جایگزین آزمون End-to-End با D1 آزمایشی و درگاه پرداخت Sandbox نیستند؛ بنابراین این صفحه ادعای تأیید نهایی پرداخت، موجودی رقابتی یا آمادگی کامل عملیاتی ندارد.

آخرین Commit شاخهٔ main: ce2f099 · ۹ نوامبر ۲۰۲۶. CI همان Commit موفق بوده و مدیریت بارگذاری تصویرهای بیش‌ازحد بزرگ را بهبود داده است. سه PR باز (#18 برای محدودسازی بدنهٔ multipart، #20 برای حفظ allowlist دقیق CORS و #22 برای اعتبارسنجی امن تغییر دستی موجودی) هنوز در main ادغام نشده‌اند و قابلیت منتشرشده محسوب نمی‌شوند. آزمون کامل خرید، D1 آزمایشی و پرداخت Sandbox همچنان جداگانه لازم‌اند.
